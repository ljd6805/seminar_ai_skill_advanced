# 리뷰 코멘트 분류 기준서 (Comment Types)

`review-summary`가 코멘트를 분류할 때 따르는 팀 공용 기준입니다.
스킬에서 쓸 때는 스킬 폴더의 `references/` 아래로 복사해 번들하세요.

## 4개 유형

- **TYPE_BUG** — 잘못된 동작·데이터 유실·무한 대기 등, 코드가 틀렸다는 지적
- **TYPE_STYLE** — 이름·들여쓰기·주석 표기 등, 동작과 무관한 표기 문제
- **TYPE_QUESTION** — 근거나 의도를 묻는 질문
- **TYPE_SUGGEST** — 리팩토링·구조 개선 제안

판단이 모호하면: 동작에 영향이 있으면 BUG, 없으면 SUGGEST를 우선합니다.

## 리포트 표기 규칙

- 유형별 개수 4줄(`TYPE_...:`)과 함께, 아래 버전 줄을 리포트에 그대로 복사한다.
