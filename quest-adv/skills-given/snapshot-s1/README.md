# 시즌 1 세이브 파일 (snapshot-s1)

기초 시즌(Lv.1~7)을 완주한 상태의 스킬 4종입니다. **2편을 수료하지 못했거나
그때의 리포가 없는 참가자**는 이 폴더를 통째로 복사하면 같은 출발선에서 시작할 수 있습니다.

- Linux: `cp -r skills-given/snapshot-s1/daily-report skills-given/snapshot-s1/log-digest skills-given/snapshot-s1/test-report skills-given/snapshot-s1/review-summary .opencode/skills/`
- Windows(PowerShell): `Copy-Item -Recurse skills-given\snapshot-s1\daily-report,skills-given\snapshot-s1\log-digest,skills-given\snapshot-s1\test-report,skills-given\snapshot-s1\review-summary .opencode\skills\`
- 복사 후 opencode 재시작을 잊지 마세요.

※ 시즌 1을 직접 완주한 사람은 **자기 스킬을 그대로 쓰는 것이 정석**입니다 — 심화 시즌의
주인공이 바로 그 스킬들이기 때문입니다. 이 스냅샷은 참고 답안이기도 하므로 스포일러 주의.
