# 품질 판정 기준서 (Quality Bar)

`test-report`가 판정을 매길 때 따르는 팀 공용 기준입니다.
기준은 분기마다 바뀔 수 있으므로 SKILL.md 본문에 직접 적지 않고 이 파일로 관리합니다.
스킬에서 쓸 때는 스킬 폴더의 `references/` 아래로 복사해 번들하세요.

## 판정 기준 (FAIL 개수 기준)

| FAIL 개수 | 판정 |
|-----------|------|
| 0         | `GRADE: CLEAN` |
| 1 ~ 3     | `GRADE: WATCH` |
| 4 ~ 7     | `GRADE: RISK`  |
| 8 이상    | `GRADE: BLOCK` |

## 리포트 표기 규칙

- 리포트에 `GRADE: <판정>` 한 줄을 그대로 포함한다.
- 어느 버전의 기준으로 판정했는지 남기기 위해, 아래 버전 줄도 리포트에 그대로 복사한다.
