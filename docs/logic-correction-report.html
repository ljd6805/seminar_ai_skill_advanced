수치와 실습을 읽는 방법

256k는 이 자료의 환경 가정이다. 예시 계산은 38k/256k ≈ 14.84%, 3.3k/256k ≈ 1.29%, 1k/256k ≈ 0.39%다. 실제 토큰 수·성능·시간 절감은 모델, 입력, 실행기와 측정 방법에 따라 달라진다. 애니메이션의 게이지와 단계별 비용은 작동 원리를 설명하는 도해이며 벤치마크가 아니다.

Before의 일부 스킬에는 문제를 재현하기 위한 제한이 의도적으로 포함되어 있다. Before/After는 기법을 이해하는 체험이지 현대 모델의 평균 성능을 비교한 통제 실험이 아니다. 슬라이드의 50만 줄·12모듈·8점검 항목과 체험 키트의 작은 입력은 규모가 다르다.

표시용 RUN: <현재 작업 ID>와 SOURCE: sha256:…는 실제 실행 값으로 바꾼다. RUN·SOURCE를 검증하려면 현재 요청과 실제 입력에서 얻은 기대값이 필요하다. 이 예제에는 범용 실행기, 강제 라우터, 자동 복구 엔진이 포함되지 않는다.

env/는 교육용으로 저장한 출력이다. cat env/health.txt의 성공은 파일을 읽었다는 뜻이며 현재 서비스의 정상 증거가 아니다. 저장된 권한 오류는 원래 점검의 ERROR로 분류한다. 원래 종료코드가 기록되지 않았다면 임의로 만들지 않는다.
