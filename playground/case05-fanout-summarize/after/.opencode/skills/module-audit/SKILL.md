# Module Audit — 조율자

## 절차
1. 대상 모듈 목록을 `output/audit/plan.md` 에 적는다. (modules/ 하위 폴더 = 조각)
2. 모듈마다 **서브에이전트(또는 새 세션)**에 위임한다.
   위임 지시문 (그대로 사용):
   > "modules/<X> 만 점검하라. 결과는 assets/report-form.md 양식
   >  10줄로 `output/audit/<X>.md` 에 저장하라. 코드 원문 인용 금지."
3. 위임이 끝나면 `output/audit/*.md` **만** 읽고 종합한다.
4. 종합 리포트에 모듈별 보고 파일 경로를 남긴다.

## 금지
- 부모 세션에서 모듈 코드를 직접 여는 행위
- 회수 시 10줄 양식을 벗어난 보고 수용 (벗어나면 반려·재위임)

## 보고 양식 (assets/report-form.md · 10줄 고정)
모듈: · 위험도(상/중/하): · 발견 1~3 (각 1줄) · 근거: 파일:줄 · 제안(1줄)
