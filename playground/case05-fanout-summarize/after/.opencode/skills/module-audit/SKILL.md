# Module Audit — 조율자

## 절차
1. 대상 모듈 목록을 `output/audit/plan.md` 에 적는다. (modules/ 하위 폴더 = 조각)
2. 모듈마다 **서브에이전트(또는 새 세션)**에 위임한다.
   위임 지시문 (그대로 사용):
   > "modules/<X> 만 점검하라. 결과는 assets/report-form.md 양식
   >  약 10줄 요약과 근거 파일·위치·확인 명령을 `output/audit/<X>.md` 에 저장하라. 긴 원문은 별도 근거 파일에 보존하고 필요한 인용만 포함하라."
3. 위임이 끝나면 각 보고를 먼저 읽고, 중요한 판단과 모듈 간 의존 관계는 해당 코드·근거를 다시 확인해 종합한다.
4. 종합 리포트에 모듈별 보고 파일 경로를 남긴다.

## 금지
- 근거 확인 없이 요약만으로 보안 점검 완료를 선언하는 행위
- 모듈 경계를 넘는 위험을 누락하는 행위

## 보고 양식 (assets/report-form.md · 약 10줄 요약 + 필요 시 상세 근거)
모듈: · 위험도(상/중/하): · 발견 1~3 (각 1줄) · 근거: 파일:줄 · 제안(1줄)

## 적용 조건
서브에이전트 기능이 있는 실행 환경에서 사용한다. 작업자별 컨텍스트는 독립적이며 하나의 큰 공유 창으로 합쳐지지 않는다. 요약은 정보를 잃을 수 있으므로 근거를 보존한다.
