# Repo Scout

## 절차 — 넓게 → 좁게 → 깊게
1. `tree -L 2` (또는 파일 목록)으로 구조만 파악한다. (내용 열람 금지)
2. `grep -rn "<심볼>" src/` 로 후보 위치를 찾는다.
   - 심볼을 모르면: 요청의 명사로 grep → 후보 확보
3. 후보 파일은 해당 함수 **±50줄만** 읽는다.
4. 부족하면 호출부를 grep 으로 따라가며 2~3을 반복한다.
5. 근거는 `파일경로:줄번호` 형식으로 남긴다.

## 금지
- 폴더를 순회하며 파일 전체를 읽는 행위
- 1,000줄 넘는 파일의 통째 읽기 (필요 범위만)
- grep 없이 "일단 열어 보는" 읽기

## 출력
- 흐름 설명 + 근거(파일:줄)
- 읽은 총량 보고 (예: 총 297줄)
