# PR 설명 리뷰 체크리스트 (팀 공유)

리뷰어 역할로 아래 항목만 본다. 통과 근거가 아니라 **결함**을 찾는다.

- #1 제목이 "무엇을/왜"를 한 줄로 말하는가
- #2 **테스트 영향**이 적혀 있는가 (추가/변경된 테스트, 수동 검증 절차)
- #3 호환성/마이그레이션 영향(설정·스키마·API 변경)이 명시됐는가
- #4 관련 이슈/티켓 링크가 있는가
- #5 **롤백 계획**이 있는가 (되돌리는 법)
- #6 리뷰어를 위한 확인 포인트(무엇을 봐야 하나)가 있는가
- #7 **과장·모호 표현**이 없는가 ("완벽히", "아마", "약간", "등등")
