# QA Desk — 라우터 스킬(접수 창구)

## 분류표
| 요청에 이런 말이 있으면        | 이 스킬로 진행    |
|--------------------------------|-------------------|
| 로그 · 크래시 · 원인           | log-digest        |
| 리포트 · 집계 · 주간           | test-report       |
| 리뷰 · 코멘트 · PR 피드백 정리 | review-summary    |
| PDF · 문서 변환                | pdf-export        |

## 분류 불가 시
- 후보 2개를 제시하고 사용자에게 확인받는다. (짐작으로 진행하지 않는다)

## 운영 규칙
- 전문 스킬의 description 은 **좁고 정확하게** 다듬는다.
  예: pdf-export → "완성된 문서의 PDF 변환" (로그 삭제)
- 새 스킬 추가 시 이 분류표에 한 줄을 함께 추가한다.

## 해석과 실행
분류표의 단어는 단서이며 정확한 문자열 매칭 규칙이 아니다. 요청 전체의 목적과 입력을 함께 본다. 복합 요청은 분석 후 문서 변환처럼 여러 스킬을 순서대로 연결한다. 이 라우터의 description만으로 최우선 호출이 보장되지 않는다. 반드시 거치게 하려면 실행기에서 진입점을 정하고 대표·경계·복합 요청으로 동작을 검증한다. 영어 description 자체가 미발동의 원인은 아니다.
