# 사건 ⑨ — 라우터 스킬 (Router Skill)

> 슬라이드: PART 2 · 사건 09 — "스킬이 스무 개가 되자, 엉뚱한 스킬이 발동합니다"

## 시나리오
스킬이 늘자 발동 판단이 description끼리의 **유사도 경쟁**이 된다.
"이 로그 좀 봐줘" → pdf-export 오발동(설명에 "로그"가 겹침),
"리뷰 코멘트 정리해줘" → review-summary 미발동(한글 트리거 표현 없음).

## 체험 방법
1. **Before** — `before/` 4개 스킬. description 을 그대로 읽어 보라.
   - "이 로그 좀 봐줘" 에 어떤 스킬이 후보로 겹치는지(log-digest vs pdf-export).
   - "리뷰 코멘트 정리해줘" 를 잡을 트리거 표현이 있는지(영문뿐).
2. **After** — `after/` 에는 `qa-desk` 접수 창구 + 분류표가 있고, 전문 스킬의
   description 은 좁게 다듬어져 있다.
   - `이 로그 좀 봐줘` → qa-desk 분류표 "로그·크래시·원인" → log-digest.
   - `그… 지난주 그거 정리해줘`(모호) → 짐작 대신 "리뷰 정리 / 주간 리포트 —
     어느 쪽인가요?" 로 **질문**하는지 확인.

## 관찰 포인트
- 입구가 하나로 모이는가(진입점 1개).
- 창구 description 은 **넓게**, 전문 스킬은 **좁고 정확하게** — 겹침도 빈틈도 사라진다.
- 모호하면 짐작이 아니라 질문이 정답.

**한 줄 정리 — 접수 창구를 세워라.** 발동 판단을 유사도 경쟁에서 명시된 분류표로.
