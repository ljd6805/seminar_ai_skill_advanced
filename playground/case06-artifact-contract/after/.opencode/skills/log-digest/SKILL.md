# Log Digest (생산자)

## 절차
1. 로그를 요약한다.
2. 결과를 표로 정리한다.
3. 결과를 `output/digest.md` 로 저장한다. (경로 고정)
4. 형식: `## 요약` / `## 오류 Top 10` / `## 이상 징후`
5. `SCHEMA: 1`, `RUN: <현재 작업 ID>`, `SOURCE: sha256:<입력 로그 해시>`를 남긴다.
   현재 요청에서 정한 RUN과 실제 입력 파일의 SHA-256을 사용한다. 표시용 예시 값을 복사하지 않는다.
6. 사용자에게는 경로만 한 줄로 알린다.

## 쓰는 쪽 약속 (요약)
- 경로: `output/digest.md` (고정)
- 형식: 위 3개 섹션 고정
- SCHEMA는 형식 버전, RUN은 작업 식별자, SOURCE는 실제 입력 내용의 식별자다.
- 해시·필드의 존재만으로 내용의 정확성이나 최신성을 보증하지 않는다.
